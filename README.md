One word, 11 letters: the single word Grandma would text about AI. A tiny deterministic program writes that one word to `/output/entry.txt` — no network, no randomness, no input files.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output file holds exactly the word plus a trailing newline: 12 bytes, inside the gate's 1–30 characters.
